WORK · FR/26_01 · FRAME / 2026

Williams HouseLinghui Design Studio
6033 Williams Rd, 里士滿, BC V7E 1K4, 加拿大
框架獎，眾議院

以安靜的中性公區串連各具色彩性格的私領域，讓既有住宅在連續與反差之間形成生活節奏。

案例背景

Williams House 是加拿大列治文一座約 1229 平方英尺的既有聯排住宅全面翻修案，2025 年完成、2026 年刊載。設計沒有抹除原屋性格，也未以單一風格統攝所有房間，而是保留可延續的空間骨架，以克制的新介入調整居住氛圍。公領域被設定為平靜的「結締組織」，私領域則容許較濃烈的色彩與個人偏好；其核心不是形式奇觀，而是讓一家住宅在共同生活與個人退隱之間出現清楚層次。

空間策略

主要策略是利用氣氛分區取代過度複雜的平面造型。客廳、餐廳、廚房與交通空間維持連續、低對比的背景，使約 114 平方公尺的住宅不因材料切割而顯得零碎；房門則成為情緒轉場的界線，每個臥室或衛浴在門後展開獨立色彩敘事。這種做法與常見全屋同色同材的住宅不同：統一性來自尺度、線條、櫃體工法及反覆出現的細節，而非所有空間看起來相同。可複製的原則是先建立穩定的公共基底，再把高彩度、深色天花或特殊木作集中於可關閉的小空間，控制視覺刺激與施工成本。

材料與光線

材料配置著重中性基底與局部濃色的重量差。公共區域以偏暖白、米灰及自然木色維持柔和反射，避免純白造成冷硬感；主臥以巧克力色天花降低視覺重心，衛浴則透過更具情緒性的色面及手工訂製木作建立辨識度。深色設於天花而非全面包覆牆面，能在保留牆面亮度的同時增加包覆感。自然光先被淺色公區擴散，進入私室後再由深色表面收斂，形成明暗節奏。收邊的關鍵在門框、櫃體端板、天花轉折與材料交界保持簡潔；若這些線位不一致，多色策略很容易退化為拼貼。

生活場景

公區適合以低背、輪廓簡潔且留有離牆空隙的家具維持視線穿透，讓日常物品而非固定裝飾成為前景。家具尺度應服從聯排住宅有限的面寬：沙發、餐桌與中島之間需保留順暢通道，避免以大型單品消耗公共空間。私室則可藉床頭木作、浴櫃及燈具建立較密實的近身尺度。此案值得學習之處，是家具沒有被要求統一成展示間套組，而是藉色溫、材質觸感及比例互相呼應，使生活場景能逐步累積，而不必一次完成。

設計語法

中性公區作為連續背景效果：降低開放區域的視覺噪音，使採光、動線與日常物件成為主角。可應用於：客餐廳相連的小宅、狹長型住宅與樓層式住宅。注意事項：中性色仍需安排冷暖、粗細與反光差異，否則容易顯得扁平或近似樣品屋。
以房門作為色彩轉場效果：關門時維持公共區域完整，開門後才揭示各房間的個性。可應用於：臥室、衛浴、書房及更衣室。注意事項：門片開啟後的視線端點必須預先設計，並協調門框、踢腳與牆色的交界。
深色天花調整私室重心效果：在不壓縮平面面積的情況下增加包覆感，並削弱制式住宅的空盒感。可應用於：主臥、閱讀角或需要安定氣氛的房間。注意事項：低樓高或自然光不足時須控制深色色值與面積，並補充柔和的間接照明。
以訂製木作串連不同色彩房間效果：讓各空間即使配色不同，仍共享一致的尺度、線條及工藝品質。可應用於：浴櫃、床頭、收納牆及入口櫃。注意事項：應先統一門縫、抽屜分割與五金位置；只追求特殊顏色會放大施工誤差。
公私領域採取不同明暗密度效果：公共空間顯得開放，私領域則更沉靜，居住節奏因而可被感知。可應用於：家庭成員需求差異較大的住宅改造。注意事項：反差仍需共享一至兩種基底材質，避免各房間成為互不相干的主題包廂。

台灣住宅可借鑑處

  • 台灣中古公寓若格局尚可，可先保留結構與主要動線，把預算集中在採光、木作、色彩及機電性能。
  • 小坪數公區宜維持低對比，將較強色彩放入臥室或衛浴，既保有開闊感，也能滿足家庭成員的個別偏好。
  • 深色天花適合局部使用，但須先評估常見的低樓高、樑位、冷氣設備與間接照明所需厚度。
  • 多色住宅要靠一致的門框、踢腳、櫃體分割及五金語彙維持秩序，不能只依賴色票搭配。
  • 聯排住宅的公私轉場可轉譯到台灣複層住宅：樓梯與走道保持平靜，各房間再發展獨立性格。

風險或限制

  • 案例資訊未交代原始平面與改造後平面的差異，難以判斷動線、收納及機能改善的實際幅度。
  • 濃色私室對自然光、樓高及人工照明品質較敏感，直接移植到陰暗或低樓高住宅可能產生壓迫感。
  • 大量訂製木作與精準色彩交界仰賴良好施工放樣，預算不足時容易在門框、矽利康及板材接縫處失真。
  • 以房間建立各自色彩故事具有個人性，但日後更換家具或轉售時，適配彈性低於全屋中性配置。
  • 公開資料未提供能源、隔音、防水、通風與材料耐久性數據，因此無法只憑視覺成果評估改造的完整性能。
  • 原始影像未能逐張進行像素層級核對，image_reading 依案例文字所述的空間主題整理，細部材質與畫面順序仍應以原圖為準。

CODE FR/26_01 · 專案頁面 獎項頁面

WORK · DZ/26_02 · Dezeen / 2026

Studio Nirvana designs Zenhouse in India to invite calm and stillnessStudio Nirvana
度假屋
德澤恩之家

它以保留樹木、取消走廊與容納「無用途空間」來製造靜謐，而非只靠灰色表面模仿禪意。

案例背景

Zenhouse位於印度喀拉拉邦帕拉卡德郊外，是供家族與朋友使用的度假住宅，也帶有重建祖輩生活記憶的意義。設計取徑接近日本禪宗所談的空、簡素、自然與平衡，但真正支撐概念的是基地上的成熟芒果樹、菠蘿蜜樹及其陰影，而非符號化的日式裝飾。與一般把度假宅做成景觀豪宅的案例不同，本案刻意保留大量不被功能命名的過渡空間，讓行走、停留和觀看樹影本身成為生活內容。

空間策略

兩層量體繞既有樹木與樹院展開，客廳、餐廳、廚房並非塞進單一大平面，而由庭院、露台和玻璃界面串成鬆散序列。設計以寬闊的中介地帶取代效率導向的走廊，使房間之間存在呼吸距離；入口則由有頂停車區、淺圓形水池逐步轉入公共空間。五間臥室分置兩層，影院、辦公、酒吧、泳池與服務設施形成次級生活群組，頂層冥想室進一步把日常動線推向安靜、向內的終點。這種策略的核心不是完全開放，而是以庭院、厚牆、轉折和視線長度控制開合節奏。

材料與光線

主色由灰色石灰灰泥、粗糙抹面及清水模板混凝土構成，飽和綠景與深色木作遂成為主要色彩事件。回收自歐洲舊屋樑材的木皮用於門片及櫃體，栽植柚木家具則緩和混凝土的骨架感。材料語法刻意少而連續：牆面不以線板切割，櫃門與設備趨向齊平，整合燈具在關閉時淡出視野，收邊重點是消除多餘陰影線與五金干擾，而不是展示精巧節點。落地玻璃、帶狀窗、狹縫天窗和泳池斜窗讓自然光以不同角度進入；樹冠遮蔭使灰牆上的光影持續變化，避免單色空間變得呆板。其風險是大面灰色在陰雨季節可能偏冷，且清水混凝土、灰泥與玻璃交界的防水、裂縫及冷凝控制必須非常精準。

生活場景

公共區尺度寬大，家具沒有填滿空間，而以長桌、低矮日床、獨立沙發和少量邊几形成可被繞行的島狀配置。深木色餐桌與櫃體提供視覺重量，低背家具維持穿越室內觀看庭院的水平視線；客廳中的Phantom Hands日床與&Tradition沙發則在粗獷外殼中加入較柔軟、可久坐的身體尺度。訂製吧台、洗手台與床榻讓固定構件延續建築比例，吊燈和落地燈只在用餐或停留位置降低光源高度。這種疏朗比例適合多人短期共聚與靜修，卻未必符合小家庭每日追求就近收納、快速家務與高使用密度的需求。

設計語法

以既有樹木決定量體缺口與庭院位置效果：讓建築秩序服從樹冠、陰影和季節變化，室內因而獲得真實的自然時間感可應用於：有老樹的透天住宅、農舍改建與低密度集合住宅注意事項：須先完成樹木健康、根域、颱風風險及施工保護評估，不能只在完工照片中把樹當布景
用可停留的中介空間取代狹長走廊效果：延長房間之間的心理距離，也讓移動、看景與短暫停坐重疊可應用於：大坪數住宅、三代宅與共居公共層注意事項：面積有限時應把中介區兼作採光、通風、閱讀或收納節點，否則容易淪為昂貴的閒置面積
限制牆地色相，以粗細、反光度和木色建立層次效果：降低視覺噪音，同時讓光影、植物與人的活動成為主角可應用於：希望安定但不想依賴裝飾的住宅室內注意事項：單色不等於單一規格；需用樣板測試日照、色溫、觸感與修補後色差
將人工照明藏入建築，僅在活動位置設置可辨識燈具效果：保持天花與牆面的完整，夜間則以局部光域界定用餐、閱讀和聚會尺度可應用於：開放式客餐廳、臥室與冥想空間注意事項：隱藏燈具必須保留散熱、檢修及更換路徑，並避免全屋只剩間接光而缺乏照度
以低家具和留白維持跨庭院的長視線效果：大型空間不因家具堆疊而破碎，室內外景深得以連續可應用於：有庭院、景觀窗或對景條件的客廳注意事項：應依住戶身高、起身能力與久坐需求調整座高，不能為了畫面一味壓低家具

台灣住宅可借鑑處

  • 老屋重建或透天開發可先以樹木根域、日照與主風向建立不可建範圍，再決定房間，而非完成平面後才補植景觀。
  • 台灣中小坪數可把走道加寬成採光書廊、家務平台或共享桌，借用本案的中介概念，但不必照搬其龐大留白。
  • 灰色系應結合石灰塗料、木皮、織品與不同反射度，並以台灣潮濕氣候下的防霉、可修補性作為選材前提。
  • 落地玻璃應搭配深簷、外遮陽、可開啟扇及除濕策略；先解決熱負荷與冷凝，才談室內外連續。
  • 家具配置可保留穿透景觀的低視線，但需同時檢核長者起身、兒童安全與實際收納量。
  • 最值得學習的不是禪風配色，而是讓基地條件、移動速度、留白和光影共同構成安靜感。

風險或限制

  • 住宅面積極大，空間留白建立在高土地與營造成本上，難直接移植到都市公寓。
  • 度假使用頻率較低，稀疏家具與分散機能對日常家務、清潔及照護未必高效。
  • 大面玻璃、泳池、桑拿與按摩池會提高冷房、除濕、維護及能源負擔。
  • 灰色石灰灰泥和清水混凝土在高濕環境容易出現水痕、色差、裂縫與黴斑，細部施工品質尤其重要。
  • 高度克制的場景可能壓縮住戶展示物件、累積記憶和因應家庭變化的彈性。
  • 入口淺水池及多處內外高差須檢討兒童、長者與無障礙安全。
  • 不同報導對總面積存在約1393平方公尺與20000平方英尺的差異，規模資料宜再向設計方核實。

CODE DZ/26_02 · 專案頁面 德澤恩之家

WORK · DZ/26_03 · Dezeen / 2026

TYPE updates London terrace home with robust and timeless materialsUnknown architect
倫敦的房子
德澤恩之家

TYPE以耐久、低彩度且可自然老化的材料，讓新家庭空間接續倫敦排屋的厚實尺度，而非刻意仿古。

案例背景

案例位於倫敦 Denmark Hill，原有維多利亞式排屋因年輕家庭的生活需求而擴建，重點包括放大首層廚房與餐廳，並增加一間臥室。設計理念不是把舊屋刷新成無歷史感的白盒子，而是以淡色磚、陶土燒製面磚及梣木木作建立具有觸感、耐磨性與時間感的新層次。新介入採取當代構造與較簡潔的線條，但材料重量、色溫及尺度仍回應排屋原有的沉著性格。

空間策略

改造核心是把首層後段由零碎服務空間轉為家庭共同使用的廚房—餐廳，利用向庭院延伸取得更完整的平面與採光面。廚房木作被視為空間界面，而不只是設備集合，使收納、操作檯與牆面形成連續秩序。新增臥室則提升垂直空間的居住容量，避免所有需求都擠壓在首層。設計語法建立在舊屋較封閉、序列式房間與新增開放家庭空間的對比：前段保留住宅的層次感，後段負責聚會、用餐及連接花園，並以材質延續而非完全拆通來維持空間節奏。

材料與光線

淡色磚提供顆粒與厚度，陶土燒製面磚帶入較溫暖的土色及細微色差，梣木則用清楚木紋調和礦物材料的冷硬感；整體色彩以米白、淺灰、蜂蜜木色和陶土色構成，避免高對比配色破壞老屋的安定感。後側增建預期由較大的庭院開口引入自然光，淺色表面可將光線向室內深處反射，木材與陶磚則防止空間因均勻明亮而顯得扁平。收邊宜以齊平門片、規律磚縫、薄而明確的交界及少量陰影縫控制；這類材料一旦轉角、填縫或木作分割失準，質樸感很容易退化為粗糙。其設計語法不是依靠單件吸睛物，而是重複運用模數、接縫、材料厚度與暖色調，形成安靜但可辨識的整體。

生活場景

擴大的廚房與餐區對應家庭早餐、兒童活動、備餐及多人聚會等重疊情境，家具配置應保留餐桌四周的通行與拉椅距離，並讓主要座位能感受到庭院光線。梣木固定木作承擔視覺秩序，活動家具則適合採線條簡單、體量偏輕的餐椅與桌具，避免與磚、陶磚的厚重感互相競爭。排屋面寬有限，因此比例控制比追求大型中島更重要：操作檯、餐桌與走道需要形成清晰層級，櫃體高度也應與門窗分格或既有簷線對齊。相較常見以全白牆面、無框玻璃和超薄構件塑造反差的排屋增建，本案更重視觸感、耐用性及材料老化後仍能共存的家庭日常。

設計語法

以淡色磚、陶土面磚與梣木組成低彩度材料家族效果：在不依賴強烈色彩的情況下，以紋理、溫度及反光差異建立空間深度可應用於：老屋翻新、透天住宅後側增建、開放式餐廚注意事項：材料樣品必須在實際日光與夜間照明下並置確認，否則米灰色容易偏冷，木色也可能顯黃
